# Estudos Java — Memória, Arrays e Listas

Repositório dedicado aos meus estudos de Java, com base no módulo **Comportamento de Memória, Arrays e Listas**, do curso de Programação Orientada a Objetos com Java, do professor Nélio Alves.

## 📚 Conteúdos estudados

### 1. Comportamento de memória
- Tipos primitivos e tipos referência.
- Diferenças entre valores e referências.
- Stack e Heap.
- Valor `null`.
- Escopo de variáveis e Garbage Collector.

### 2. Arrays (vetores)
- Declaração e instanciação de arrays.
- Acesso aos elementos por índices.
- Uso do atributo `length`.
- Percorrendo arrays com estruturas de repetição.
- Arrays de tipos primitivos e de objetos.

### 3. Arrays de objetos
- Armazenamento de referências para objetos.
- Instanciação de objetos em posições do array.
- Verificação de posições vazias com `null`.
- Exercícios práticos com classes e objetos.

### 4. Boxing, Unboxing e Wrapper Classes
- Conversão entre tipos primitivos e objetos correspondentes.
- Classes como `Integer` e `Double`.
- Conversões automáticas entre valores primitivos e wrappers.

### 5. Listas
- Interface `List` e implementação `ArrayList`.
- Adição, remoção e consulta de elementos.
- Métodos `add()`, `remove()`, `size()` e `indexOf()`.
- Uso do `for-each`.
- Busca e filtragem de elementos.

### 6. Matrizes
- Declaração e utilização de arrays bidimensionais.
- Acesso por linhas e colunas.
- Percorrendo matrizes com laços aninhados.
- Exercícios com diagonal principal e números negativos.

## 🎯 Objetivo

Consolidar os fundamentos de Java por meio de anotações, exemplos de código e exercícios práticos, desenvolvendo a capacidade de compreender e resolver problemas utilizando arrays, listas, matrizes e referências a objetos.
