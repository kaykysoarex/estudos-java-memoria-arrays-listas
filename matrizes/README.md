# Matrizes em Java

## O que são?
Matrizes são estruturas que armazenam dados organizados em linhas e colunas. Em Java, podem ser entendidas como arrays dentro de outros arrays.

## Características
- Organizam os dados em duas dimensões.
- Possuem linhas e colunas.
- Utilizam dois índices para acessar os elementos.
- Os índices começam em `0`.

## Acesso aos elementos
O primeiro índice representa a linha e o segundo representa a coluna.

## Resumo
Enquanto um array comum utiliza um índice, uma matriz utiliza dois índices para localizar um elemento: linha e coluna.
